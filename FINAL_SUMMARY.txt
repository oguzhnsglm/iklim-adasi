🔧 TEKNİK DETAYLARı
═════════════════════════════════════════════════════════════════════════════

DEPENDENCIES (Gerekli):
├── expo ~54.0.0
├── expo-linear-gradient ~13.0.2
├── expo-blur (requires installation)
├── react-native 0.81.5
├── @react-native-async-storage/async-storage ~2.2.0
└── expo-av (already included)

PROVIDER YAPISI:
<ThemeProgressProvider>
  <ThemeWorldsProgressProvider>
    <ParentSettingsProvider>
      <MascotProvider>
        <TreePlantingProvider>           ← YENİ
          <AppInner />
        </TreePlantingProvider>
      </MascotProvider>
    </ParentSettingsProvider>
  </ThemeWorldsProgressProvider>
</ThemeProgressProvider>

VERİ YAPISI (Tree Object):
{
  id: string,              // Unique ID (timestamp)
  timestamp: ISO string,   // Dikme tarihi
  stage: 0-3,              // 0=Toprak, 1=Filiz, 2=Fidan, 3=Ağaç
  emoji: string,           // 🌍→🌱→🌿→🌳
  name: string,            // User-friendly name
  ...customFields          // Genişletilebilir
}
