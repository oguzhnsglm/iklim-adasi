3. AĞAÇ DIKME İŞ AKIŞI
═══════════════════════════════════════════════════════════════════════════

    Kullanıcı TreePlantingCard'a dokunur
         ↓
    animateTreeGrowth() çalışır
         ↓
    plantTree() çağrılır (TreePlantingContext)
         ↓
    Yeni Ağaç Objesi Oluşturulur
    {
      id: "1234567890",
      stage: 0,
      emoji: "🌱",
      name: "Ağaç #1"
    }
         ↓
    4 Aşamalı Animasyon Başlar
    
    Aşama 0: 🌍 (Toprak)
    ├── Duration: 400ms
    ├── Glow Effect: ON
    └── Wait: 600ms
         ↓
    Aşama 1: 🌱 (Filiz)
    ├── Duration: 400ms
    ├── Glow Effect: ON
    └── Wait: 600ms
         ↓
    Aşama 2: 🌿 (Fidan)
    ├── Duration: 400ms
    ├── Glow Effect: ON
    └── Wait: 600ms
         ↓
    Aşama 3: 🌳 (Ağaç)
    ├── Duration: 400ms
    ├── Glow Effect: ON
    └── Tamamlandı!
         ↓
    updateTreeStage() ile durum güncellenir
         ↓
    AsyncStorage'a kaydedilir
         ↓
    Ağaç Sayısı Artırılır (+1)
         ↓
    Bottom Info güncellenir
    "🌳 Bugün dikildi: X ağaç"


4. STATE MANAGEMENT - TreePlantingContext
═══════════════════════════════════════════════════════════════════════════

    TreePlantingContext
    │
    ├── State:
    │   ├── trees: Tree[] (tüm ağaçlar)
    │   ├── totalTreesPlanted: number
    │   └── loading: boolean
    │
    ├── Functions:
    │   ├── plantTree(data) → Tree | null
    │   │   └── AsyncStorage'a kaydeder
    │   │
    │   ├── updateTreeStage(treeId, stage) → void
    │   │   └── Ağaç aşamasını günceller
    │   │
    │   ├── clearAllTrees() → void
    │   │   └── Tüm ağaçları siler
    │   │
    │   └── getLastPlantedTree() → Tree | null
    │       └── Son dikilen ağacı döndürür
    │
    └── AsyncStorage:
        └── KEY: "treePlantingData"
            └── Data: JSON.stringify(trees)


5. ANIMASYON TIMELINE
═══════════════════════════════════════════════════════════════════════════

    T=0ms
    │
    ├─ fadeInAnim: 0 → 1 (800ms) ↓
    ├─ slideUpAnim: 50 → 0 (800ms) ↓
    ├─ scaleAnim: 0.95 → 1 (800ms) ↓
    │
    T=400ms
    ├─ cardSlideAnim: 100 → 0 (600ms) ↓
    │
    T=1000ms
    │ (Tüm animasyonlar tamamlandı)
    │ Splash screen tamamen görülebilir
    │
    (Kullanıcı OYUNA BAŞLA'ya basarsa)
    │
    T=1000ms+
    ├─ fadeInAnim: 1 → 0 (400ms) ↓
    ├─ slideUpAnim: 0 → 50 (400ms) ↓
    │
    T=1400ms
    │ Splash kapatılıp Main App yüklenir
